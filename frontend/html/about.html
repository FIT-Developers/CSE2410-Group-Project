About Campus Navigator

Built by Florida Tech students for CSE2410 (Intro to Software Engineering) to make navigating campus buildings, amenities, and daily schedules effortless.

The Problem

Why We Built This

Finding specific academic buildings, dorms, dining hours, and parking lots on campus can be confusing—especially for new students and visitors. Campus Navigator puts everything into one fast, mobile-friendly map.

Features

What It Does

  • Interactive satellite campus map with custom building markers
  • Live GPS user tracking and turn-by-turn walking routes
  • Day-of-the-week filters (M-F) and building operating hours
  • Quick access to building photos, types, and official websites
Course & Stack

CSE2410 - Fall 2026

Developed by FIT-Developers using HTML5, modular CSS, Vanilla JavaScript, Leaflet.js, and a Java Spring Boot backend API for routing and user accounts.
